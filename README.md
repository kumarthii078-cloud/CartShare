Carts - E-Commerce Website

A simple e-commerce website built using HTML, CSS, and JavaScript.

Features

- Product display
- Shopping cart
- Add and remove products
- Receipt generation
- Local storage

Technologies

- HTML
- CSS
- JavaScript

How to Run

1. Open "index.html" in your browser.
2. Browse the products.
3. Add products to your cart.
